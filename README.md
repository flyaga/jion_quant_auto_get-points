# 聚宽自动领积分脚本
聚宽自动领积分node.js脚本，支持聚宽多账户同一个密码自动领积分，支持自动进行滑动验证，支持当天多次运行实际只领积分一次。

# 使用说明
首次运行需要先安装chrome和node.js，然后clone本脚本，再编辑jq_checkin.bat，改成你的聚宽用户名和密码，最后运行此批处理或者加入到开机自启动或者加入到定时任务中。
